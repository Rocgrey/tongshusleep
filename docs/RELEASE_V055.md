## 服务器兼容

- `ClassroomCatalog.json` 的五个章节分别填写自己的图片资源名。
- 已知官方五讲视频若收到空封面、`course-cover`、旧 `course-cover.jpg` 地址或与系列相同的总封面，App 显示对应的本地独立封面。
- 后台发布其他专门的章节封面时直接优先显示，不覆盖管理员的新图。不修改视频地址、学习进度、发布状态、权限或其他内容。
- 匹配依据为已确认的视频业务域名和精确视频路径，不按相似课程名称或未知视频推测封面。
- 本次不需要 Web 部署、数据库迁移或调整接口。当前直接访问部署内容接口返回 403，因此没有将线上内容读取宣称为本次已完成的真实联调；旧服务器返回的兼容行为通过测试后端验证。
