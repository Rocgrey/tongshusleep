# 测试与试用

## 手动试用

1. 启动后确认首页标记“示例数据”，查看总时长与参考分。
2. 点左右箭头或日期切换到另一晚，确认图表与统计同时改变。
3. 点参考分或体征格子，阅读计算与数据说明。
4. 打开“趋势”，切换 7/30 天和时长/效率/深睡，点每日记录查看详情。
5. 点首页右上角加号，选择跨夜时间并保存，确认新增的“手动记录”不会显示虚构的体征。
6. 在“设备与数据”调整目标，确认首页目标和时长图参考线更新。
7. 导出 JSON；先保存到自己知道的位置；导入相同文件，确认重复 ID 被跳过。
8. 移除示例后重新打开 App，确认示例不会自动恢复，手动记录仍在。
9. 在 iPhone 真机点击扫描，测试拒绝权限、蓝牙关闭、设备离线和连接超时。

不要将“已连接”当成“小米睡眠同步可用”。当前并未适配小米私有睡眠协议。

## 自动化覆盖

单元测试覆盖：30 晚示例的分期连续性和总时长一致性、手动缺失值、备份往返、重叠/间隙/异常体征/不支持版本拒绝、SwiftData 写入后重开和删除。

UI 测试通过 `-ui-testing` 使用隔离的内存数据库，不清空正常 App 的记录。测试包含日期切换、说明弹层、趋势选择、记录详情、添加记录和移除示例。截图保存到 xcresult 附件。

## 当前限制

- 示例参考分未经医学验证。
- 尚无 HealthKit、小米协议、后台同步或远程服务器实现。
- 备份导入导出使用系统文件面板，需人工完成端到端文件选择测试。
- BLE 必须使用真机及具体手环验证；自动化测试不声称覆盖真实硬件。
- 当前默认浅色外观；视图内容最大宽度 680 点，支持 iPhone、iPad 和 Mac Catalyst。
