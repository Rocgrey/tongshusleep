# 系统健康刷新反馈：0.3.2（16）

## 最大摄氧量

HealthKit 提供最大摄氧量（VO₂ max）数据类型。本 App 已将它列入读取范围，并在健康记录及心肺参考分析中展示。是否读到数值取决于设备、运动记录或配套 App 是否把最大摄氧量写入系统健康；开启授权不会自动产生数据。页面显示“数据不足”通常表示最近没有符合条件的记录。

## 刷新结果

点击“更新健康数据”后，读取进度和结果都显示在健康页，不另外打开空白页。读取成功后将新快照与上次快照比较：有新增记录或已有记录发生变化时提示“健康数据已更新，读取到新增记录。”；没有变化时提示“暂时没有新的数据可以更新，当前数据已是最新的。”读取失败则保留旧数据并在当前页说明失败。

变化检测按记录 ID 比较，并检查指标、数值和时间区间。首次读取到空数据时不会声称有新记录。

## 验证

- 单元测试覆盖新增、变化、无变化及首次空读取。
- HealthKit 权限、查询和设备写入依赖真实 iPhone 与实际数据源；模拟器不能证明用户设备中存在最大摄氧量记录。
