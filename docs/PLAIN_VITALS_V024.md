# 0.2.4：更容易看懂的睡眠与体征

日期：2026-10-29。版本 0.2.4（6）。本说明优先于旧版操作说明。

## 界面变化

- 监测方式改为“手机监测 / 设备检测”，扫描按钮改为“搜索蓝牙”。只是入口命名调整，仍按当前支持的戒指名称、服务和已记忆标识筛选，没有新增手环协议或任意蓝牙兼容能力。
- 睡眠说明改用短句与日常例子，保留真实公式和必要限制，不再加入 N1/N2/N3 等术语。参考资料显示中文译名、英文原文标题与作者，不显示网址、外链图标或跳转。
- 外文资料展示明确标注的中文译名，并同时附上英文原文标题，不冒充中文原文。作者已核对：睡眠阶段 Eric Suni；深睡 Danielle Pacheco；睡眠质量 Eric Suni。机构文章用机构署名，自定义参考分不引用无关资料为其权重背书。
- 血糖、总胆固醇、甘油三酯、高/低密度脂蛋白和尿酸不再由 App 提取、解析或保存新值；体征页与计数、导出均不展示这些项目。旧文件中的这些值保留以兼容历史数据，不自动擦除；明确清空本地体征仍删除整个体征文件内容。底层 SDK 的全量历史传输可能仍有内部缓存，不宣称改变厂商 SDK 内部行为。

## 体征图表

同一设备、同一指标单独统计，近 7 天/30 天包含今天，截止当前时间；没有记录的日期不补成零。仅有一条值也可以显示，只有实际提供的项目才出现。

1. 每次记录：散点图，按时间显示记录，选中位置可查看附近记录的数值和时间。没有把稀疏点连成全天连续曲线。
2. 每天范围：竖条是当天已有记录的最低至最高值，圆点是算术平均；一天一条记录时只有一个点。它不表示全日最低/最高或测量覆盖完整。
3. 数值分布：在当前最小至最大之间分成四段，统计每段有多少条。相邻边界仅计一次，末段含最大值；全部数值相同则只有一段。不把条数当成持续时间，不把分组当成正常/异常等级。

顶部保留最新值选择、样本平均、最低、最高和记录天数。每个指标有日常说法解释和适用的参考，原始记录折叠以减少页面拥挤。所有统计只基于已有样本，不代表整晚或全天。

## 一般参考与适用情况

| 项目 | 页面参考 | 限制 |
| --- | --- | --- |
| 心率 | 安静清醒成人 60–100 次/分 | 睡眠及运动者可能更低，活动时可能更高；不按安静范围给混合活动/睡眠数据判级 |
| 血氧 | 一般 95%–100% | 高海拔、已有肺部疾病可能不同；唯一添加淡色参考带的图，读数偏低须确认佩戴/可靠复测 |
| 呼吸率 | 安静清醒成人 12–18 次/分 | 所引资料的安静成人参考，不当成睡眠标准；没有数据不新增项目 |
| 血压高压/低压 | 一般安静成人 90–120 / 60–80 mmHg | 两数一起看；设备历史值不等于经过验证的上臂血压测量，不用于决定用药 |
| HRV | 不设置统一正常值 | 当前设备单位与算法未确认，不能写成毫秒或当成某种特定算法；观察同设备自身变化 |
| 压力 | 不设置正常范围 | 当前设备评分范围与算法未确认，不把数值解释为焦虑诊断或健康等级 |
