# BIO 本机睡眠计算

## 本次接入

2026-11-15 新提供的 `aian/iwown_ble_demo_ios_260622` 包含 `IVSleep.a` 和 `IVSleep.h`。这是可链接到 iPhone App 的闭源本地算法库；头文件是调用说明，静态库是实际执行的计算代码。它不是蓝牙接口，也不是公开的算法源代码。

App 已接入 `ivSleepDataFromV2:andTodayPath:andDate:andRriData:andError:`。输入为前一天、当天的真实健康/睡眠 JSON，以及按日期整理的心跳间隔 RRI。原厂阶段编码为深睡 3、浅睡 4、清醒 6、快速眼动 7。没有返回的阶段不补造。

本机计算优先，不调用云端睡眠分析，也不需要厂家云算法账号。现有 App 登录及采集归属检查保留。关闭账号自动同步后，本机计算仍可运行；再次开启时，结果沿用现有 `health/device-sync` 上传。没有新增后端接口、ISI 字段或自动录音上传。

## 输入与结果规则

- 复用已有 `BIOSleepAlgorithmRequest` 和后台 `WearableProbeWorker`，合并同设备、同账号的有界历史。健康 JSON 保留 Q/T/E/H/P/V，按测量时间去重，时区沿用已实测的 BIO UTC+8 口径。
- RRI 按高 16 位、低 16 位解出有符号值，保留负值控制标记。参照厂家 Android `NativeInvoker.calculateSleepFileWithAF` 的适配实现，在前一天与当天之间插入 `-1000` 日期分隔标记；去除相邻重复的 `-1`，不插值、不补缺失信号。iOS 厂家单日示例文件也以 `-1000` 开始。
- 使用输入对应的 `yyyyMMdd`。厂家 Demo 的样本是 6 月 3/4 日，调用代码却硬编码为 `20260305`；本 App 不沿用该日期。
- 后台串行调用，原始文件只写入受保护的临时目录，调用结束删除。桥接立即复制结果，并按该固定版本实际采用的 C++ `new[]` 方式释放阶段数组；处理可捕获的 Objective-C/C++ 异常。
- 结果经过现有日期、范围、顺序、重叠和阶段校验才保存。缺口保留为未记录，未知编码不映射为浅睡或清醒。
- 按睡眠结束日更新同一份夜间记录，保留备注和 AIS，匹配实际睡眠区间内的心率、血氧及其他已有采样。无有效结果保留夜间观测，某日失败不阻断其他日期。
- 本机库没有提供完成标志，App 不擅自声明为最终报告。同一输入在本次运行中只算一次，新输入继续更新。
- 图表复用阶段时间轴、阶段环图、趋势和体征散点图。未返回的 BIO 阶段在汇总显示 `--`，不上传为 0；真实返回的清醒信息沿用已有覆盖检查和次数计算。
- 最新诊断保存在 `Documents/wearable-validation/bio-sleep-status.json`，并按日期另存 `bio-sleep-status-yyyyMMdd.json`，包含引擎、输入数量、阶段数量和状态，不含凭证或原始数组。

## 构建配置

厂家库保留在本机 `Vendor/IwownSleep/`，不随源码上传；使用原厂家包安装：

```sh
bash scripts/setup-iwown-sleep.sh "/path/to/AutumnTest/AutumnTest/Classes/VCs/SubVCs/SyncData/Sleep"
```

脚本校验本次文件 SHA-256 后复制 `IVSleep.a` 和 `IVSleep.h`，防止无意混用其他版本。库 SHA-256 为 `9c932284b3a6d269b5861d788bd212bad203206751ab8d7a934d546753c933ea`。

`Configuration/Service.xcconfig` 引入 `IwownSleep.xcconfig`，普通和戒指工程共用桥接头 `AppBridge.h`。仅 `iphoneos` 链接厂家库；模拟器及 Mac Catalyst 不链接这份 iPhone 二进制，不宣称执行过本地算法。模拟器仍可测试既有云接口适配和明确标注的测试结果。

## 操作

1. 打开已安装的 App 并登录，保持前台。
2. 结束其他配套 App 的设备同步，在“监测与设备”连接 BIO，等待读取完成。本机已有历史也会被检查，不必先读取系统健康。
3. 在“睡眠 → 设备记录”点击日期，选择已有过夜记录。有效结果会出现深睡、浅睡、快速眼动及实际返回的清醒阶段。
4. 没有完整输入的日期仍显示夜间观测。没有 RRI 或信号不足时不能保证得到快速眼动；厂家算法结果也不保证与其他版本的配套 App 完全一致。
5. 新结果只在本机保存；开启原有账号自动同步时，按既有设置同步到当前账号。
