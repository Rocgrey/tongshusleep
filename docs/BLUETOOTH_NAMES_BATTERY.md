# 蓝牙名称与设备电量（0.2.4，构建 8）

- 搜索展示附近可发现的 BLE 设备。优先使用广播名称，其次使用系统名称；重复广播没有名称时保留上次名称。两者都没有时显示“未命名蓝牙设备”及标识后缀，不推断为戒指。
- 蓝牙列表、连接标题和已保存设备显示设备实际名称；通用说明仍不使用品牌名称。搜索结果扩大不代表增加设备协议支持，受支持的戒指仍按已有通道识别、验证并自动同步。
- 连接后自动读取电量。标准通道使用 180F / 2A19；戒指专用通道在验证后调用官方 SDK 的 `veepooSDKReadDeviceBatteryInfo:`，再开始原有历史同步。电量没有响应时最多等待 4 秒，不阻止睡眠和体征同步；取消时清理等待任务。
- 设备返回 0–100 的百分比时显示百分比和电量条；只返回 0–4 格时显示格数，不把格数伪装成精确百分比。拒绝超范围值，0 为有效电量。
- 专用通道同步结束后按原有行为断开连接，保留本次读取的电量并标注设备名、读取时间和“当前已断开”；开始连接另一台设备时不会沿用上一台的电量。此电量仅在当前页面会话保留，不写入健康测量记录。
- 界面测试电量仅在 DEBUG 且同时带有 `-ui-testing` 和 `-ui-testing-battery` 时启用，不进入正常连接流程，不保存为真实数据。

## 验证范围

名称优先级、无名称回退、百分比与格数校验、设备切换清理，以及电量界面与原有设备入口的 UI 测试。真机安装后的实际电量仍以戒指回传结果为准。

本次验证：37 项单元测试通过；百分比、格数及原有设备/本地数据导航 3 项 UI 测试通过，截图无文字重叠；戒指版本真机构建及签名验证通过，已覆盖安装到连接的 iPhone 并打开设备检测页面。没有删除或重置本地数据。尚未观察到真实戒指的电量回包，需重新连接后确认具体值与单位。
